# Runtime evidence location

No runtime qualification evidence is present in this specification package.

Store actual results here, or reference a durable authorized artifact store with integrity metadata. Organize by immutable source revision, release profile and run ID; do not overwrite a failed run with a successful one. Include the qualification tuple and commands required by [ACCEPTANCE.md](../ACCEPTANCE.md).

Synthetic schema examples and specification-validation reports are separate and cannot establish runtime success. Keep credentials and confidential raw inputs out of version control. Evidence referenced by a public release needs a deliberate redaction/publication decision.
