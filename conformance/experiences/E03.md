# E03 — Create and retain a useful capability-based view

Qualification: not implemented. This is an acceptance specification, not a record of an executed test.

## Given

At least two real capabilities expose versioned schemas and authorized queries. A real model can propose a view, and a constrained renderer supports the required components. The user has view creation and limited operation authority.

## When

**E03-T1.** Ask for a task-specific tool, discover capabilities and inspect the proposed view and its effect summary.

**E03-T2.** Validate/render the view, edit a parameter by direct manipulation and invoke its real operations.

**E03-T3.** Save and reopen the versioned view with inference disabled; deterministic bindings continue to work.

**E03-T4.** Export the view without credentials and use CLI invocation to compare the underlying operation semantics.

## Then

The result is a persistent declarative artifact with live typed bindings and real output, not a screenshot. It records which operations need inference. User control remains usable without continued conversation.

## Required negative and interruption paths

**E03-N1.** Inject an unknown component, privileged script or undeclared network URL: validation/rendering refuses it.

**E03-N2.** Revoke a binding’s target permission after opening: invocation is denied even if the control remains visible.

**E03-N3.** Change a capability version or target revision: negotiation or review refresh is required according to the contract.

## Evidence

Generated and user-edited view versions; renderer validation; actual broker calls/receipts; output artifacts; reopened no-model demonstration; accessibility results.

Use the environment/claim rules in [ACCEPTANCE.md](../ACCEPTANCE.md). The implementing package supplies executable commands and assertions as the real implementation is written; no illustrative command here is represented as an existing CLI.

## Variants and guarantee limits

A hand-authored view qualifies deterministic rendering only. The full generated-view claim additionally requires the real-model generation path.
