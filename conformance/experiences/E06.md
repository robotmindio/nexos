# E06 — Turn a demonstration into a bounded procedure

Qualification: not implemented. This is an acceptance specification, not a record of an executed test.

## Given

The user opts in to capturing named semantic operations. Test inputs, secrets and nonconsented activity are distinguishable. A proposed procedure can be validated in an isolated managed workspace.

## When

**E06-T1.** Perform a real multi-step task through semantic operations while the consented capture is visible.

**E06-T2.** Inspect proposed parameters, domain/preconditions, required capabilities, effect summary and failure behavior.

**E06-T3.** Validate against a different in-domain input and a counterexample, edit the procedure and register a version.

**E06-T4.** Replay on a new authorized input with inference disabled and inspect the resulting effects.

## Then

The saved procedure is an executable bounded composition, not coordinate playback. It obtains the current caller’s authority; the demonstrator’s grants and credentials are not embedded.

## Required negative and interruption paths

**E06-N1.** Use an out-of-domain parameter or changed privileged target: reject or seek the contract-required review.

**E06-N2.** Enter a marked secret and perform unrelated nonconsented actions: neither appears in capture or derived context.

**E06-N3.** Interrupt replay, revoke authority or change a dependency version: partial results and required recovery remain explicit.

## Evidence

Consent/capture scope; semantic event sample; parameter/domain validation including counterexample; procedure versions; secret-leak inspection; real deterministic replay receipts.

Use the environment/claim rules in [ACCEPTANCE.md](../ACCEPTANCE.md). The implementing package supplies executable commands and assertions as the real implementation is written; no illustrative command here is represented as an existing CLI.

## Variants and guarantee limits

A useful first procedure can be small. Generalization beyond its declared input domain and application set remains unqualified.
