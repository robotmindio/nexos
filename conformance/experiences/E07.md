# E07 — Cooperate across two nodes and survive a partition

Qualification: not implemented. This is an acceptance specification, not a record of an executed test.

## Given

Two real nodes have authenticated identities, declared resource offers and qualified enforcement. The workspace’s authoritative writer and lease/fencing policy are explicit. A task supports checkpoint transfer.

## When

**E07-T1.** Join the nodes under an authorized policy and admit a scoped remote task/resource allocation.

**E07-T2.** Execute and persist a compatible checkpoint, then induce a real network partition.

**E07-T3.** Expire the previous lease, admit a replacement where policy allows and fence stale commits.

**E07-T4.** Reconnect, reconcile receipts/liability and continue from the declared checkpoint.

## Then

Only current authority can commit work at fenceable managed boundaries. Local actions within valid local grants continue; unavailable remote work is visible. Nodes do not silently duplicate authority or budget.

## Required negative and interruption paths

**E07-N1.** Replay an old lease or checkpoint from another workspace, use an unauthorized node and submit a stale commit.

**E07-N2.** Exercise delayed messages, node reboot and the declared clock-skew assumptions.

**E07-N3.** Invoke a non-fenceable external provider across failure: expose its weaker guarantee and ambiguous outcome rather than claiming universal fencing.

## Evidence

Both node/environment identities; network fault commands; lease/fence history; actual stale rejection; checkpoint compatibility; provider invocation/receipt comparison and final state.

Use the environment/claim rules in [ACCEPTANCE.md](../ACCEPTANCE.md). The implementing package supplies executable commands and assertions as the real implementation is written; no illustrative command here is represented as an existing CLI.

## Variants and guarantee limits

Two containers sharing one untested host boundary cannot establish every two-node claim. The qualified tuple states precisely which isolation and network boundaries were exercised.
