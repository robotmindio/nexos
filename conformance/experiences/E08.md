# E08 — Use ordinary computing and managed work without AI

Qualification: not implemented. This is an acceptance specification, not a record of an executed test.

## Given

A qualified local runtime is installed on its target Linux environment. Model access and optional cloud integrations are disabled. At least one conventional editor/application is available under a named compatibility profile.

## When

**E08-T1.** Open the workspace and conventional application, edit a real document and inspect authorized artifacts.

**E08-T2.** Use CLI and shell to perform a bounded managed operation, branch state and inspect receipts.

**E08-T3.** Pause/restart work and recover from a supported checkpoint while remaining offline.

**E08-T4.** Navigate the critical flow by keyboard/accessibility interfaces and export authorized work.

## Then

Useful deterministic work, authority and recovery remain available. Inference-dependent actions state that they are unavailable; they do not block the desktop or silently invoke a cloud model. Compatibility profile boundaries are visible.

## Required negative and interruption paths

**E08-N1.** Disable an optional service and required-model endpoint; verify local behavior and explicit unavailable state.

**E08-N2.** Remove a required sandbox facility and verify rejection of that workload profile without breaking allowed ordinary operation.

**E08-N3.** Attempt cross-workspace access/export and inspect conventional-app actions outside managed mediation for truthful scope labels.

## Evidence

Disabled-provider/network conditions; actual application and CLI operations; artifacts/receipts; restart recovery; accessibility findings and export inspection.

Use the environment/claim rules in [ACCEPTANCE.md](../ACCEPTANCE.md). The implementing package supplies executable commands and assertions as the real implementation is written; no illustrative command here is represented as an existing CLI.

## Variants and guarantee limits

The runtime profile need not be a bootable NexOS distribution. Boot/install/update claims are E10; an existing Linux desktop may host the shell.
