# P08 — Causal artifacts, knowledge and controlled memory

Status: implementation and qualification pending. Dependencies and coverage are canonical in [plan.json](../plan.json); mutable state is in [state.json](../state.json).

## User-visible outcome

A person or authorized agent can trace an artifact to observed inputs and effects, distinguish claims from evidence and correct derived memory without altering operational truth.

## Implementation work

1. Extend actual receipt/artifact records into authorized lineage queries with content digests, causal links, missing-evidence states and retention rules.

2. Audit NoemaDB/Knowledge interfaces at pinned revisions. Integrate semantic retrieval as a projection of authoritative facts where appropriate; do not create a second semantic database.

3. Implement provenance-aware context retrieval, corrections, reindexing, export and payload deletion. Tombstones preserve permitted audit structure without retaining deleted private content indefinitely.

4. Keep OpenTelemetry diagnostic traces separate from the durable authoritative effect ledger. Trace sampling or backend outages cannot erase transaction correctness.

## Acceptance

**P08-A1.** E05 reconstructs a real artifact’s observed lineage and verifies accessible digests; unavailable evidence is shown as unknown, not invented.

**P08-A2.** Cross-workspace queries, index results and inferred relationships obey the current authorization policy.

**P08-A3.** Deletion or revocation removes payload access from canonical stores and derived indexes according to the declared retention workflow.

**P08-A4.** A correction updates derived memory while preserving the original permitted receipt history and clear claim status.

**P08-A5.** Core lineage/receipt inspection works without the optional semantic service; richer retrieval reports its actual availability.

## Failure and recovery coverage

Missing parent evidence, corrupted artifact digest, stale embedding/index, revoked source, indexing failure and telemetry outage.

## Scope boundary

Omniscient host surveillance, automatic scientific truth, guaranteed causal explanations or replacing provider-owned data with duplicate canonical copies.
