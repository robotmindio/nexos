# P09 — Demonstration to bounded reusable procedure

Status: implementation and qualification pending. Dependencies and coverage are canonical in [plan.json](../plan.json); mutable state is in [state.json](../state.json).

## User-visible outcome

A consented sequence of semantic actions becomes an inspectable parameterized procedure that a human can validate, edit and execute without its original model.

## Implementation work

1. Capture opted-in semantic operations and selected public parameters, not unrestricted screen/input recording. Exclude credentials and private fields at the capture boundary.

2. Propose parameters, preconditions, output contracts, effect summaries, limits and failure/recovery behavior. Let the user confirm generalization boundaries.

3. Validate against isolated real test data, including a counterexample outside the allowed domain. Register a versioned procedure with a bounded capability contract.

4. Use fresh caller authority at replay; never serialize the demonstrator’s grants into a transferable procedure. Pin dependencies or require explicit compatible upgrades.

## Acceptance

**P09-A1.** E06 captures and parameterizes a real multi-step operation and replays it on a different authorized input without inference.

**P09-A2.** A parameter outside the validated domain and a changed privileged target are rejected or sent for the specified review.

**P09-A3.** Credential entry and nonconsented application activity are absent from captured payloads and derived context.

**P09-A4.** Revoked authority prevents replay even when a saved procedure was created under stronger authority.

**P09-A5.** Interrupted replay reconciles committed steps using provider semantics and exposes partial completion.

## Failure and recovery coverage

Overgeneralized parameter, hidden side effect, dependency version drift, cancellation, partial success and withdrawn capture consent.

## Scope boundary

Universal program synthesis from screen coordinates, automatic safe generalization or treating a successful demonstration as exhaustive validation.
