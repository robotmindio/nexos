# P01 — First real managed operation through the broker

Status: implementation and qualification pending. Dependencies and coverage are canonical in [plan.json](../plan.json); mutable state is in [state.json](../state.json).

## User-visible outcome

A human uses a deterministic CLI to create a managed workspace, discover one capability, invoke it with bounded authority and inspect an actual artifact and effect receipt.

## Implementation work

1. Implement the initial Rust modular daemon and CLI with the agreed transport and schemas. Authenticate callers without treating a claimed principal ID in JSON as proof. Use explicit workspace membership and deny absent grants.

2. Provide one real local artifact operation in a controlled worker. Write the intent-to-dispatch record before dispatch; persist outputs and an attributable receipt. Use the actual filesystem and canonical metadata store.

3. Expose discovery, invocation, execution status and receipt inspection. Enforce one concrete workspace/operation limit and a basic reservation so the vertical path already exercises admission.

4. Keep the process layout small. The first useful operation precedes a broad plugin ecosystem, generated UI or remote service requirement.

## Acceptance

**P01-A1.** From a clean managed workspace, the CLI produces a real artifact whose bytes and digest match the returned receipt, then reads it after daemon restart.

**P01-A2.** The same operation without a grant, against another workspace or with an incompatible contract version is denied without a target mutation.

**P01-A3.** An exact safe retry uses the same effect identity and returns its existing outcome; a reused idempotency key with changed input is rejected.

**P01-A4.** Kill the daemon before and after recording dispatch and document the observed recovery states. An ambiguous result is not rewritten as success.

**P01-A5.** The complete happy path succeeds with model access disabled and no optional RobotMind service online.

## Failure and recovery coverage

Inject malformed requests, stale revisions, store-write failure and worker exit. Keep denial/error receipts distinct from committed-effect evidence.

## Scope boundary

The package does not qualify hostile native workloads or all isolation profiles; P02 establishes those boundaries before agents receive them.
