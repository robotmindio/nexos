# P05 — Human workspace shell and intervention

Status: implementation and qualification pending. Dependencies and coverage are canonical in [plan.json](../plan.json); mutable state is in [state.json](../state.json).

## User-visible outcome

A person can complete useful managed work through a stable graphical workspace, inspect ongoing activity and intervene precisely without using chat.

## Implementation work

1. Build the workspace surface over actual broker queries: workspace switcher, artifact view, task/agent status, branch comparison, receipts and authority controls. Reuse an existing desktop/compositor and application launcher.

2. Expose preview, run, pause, cancel, revoke, retry, reconcile and restore only where contracts support them. Present partial and unknown outcomes as actionable states.

3. Use the same operations from CLI and UI. A hidden button does not enforce policy; every invocation is independently checked.

4. Keep layout stable, support keyboard/screen-reader operation and show freshness, scope and provenance. Conventional applications remain usable under an explicitly named compatibility profile.

## Acceptance

**P05-A1.** A user completes E01, E02 and E04 through the shell, with resulting artifacts and receipts identical in semantics to CLI operations.

**P05-A2.** Disconnect/reconnect and daemon restart preserve meaningful state; stale screens refresh before dispatching reviewed changes.

**P05-A3.** No-model/offline E08 completes: open a conventional application, edit managed data, inspect history, branch and recover.

**P05-A4.** Keyboard navigation and accessible labels cover the entire critical flow; errors describe what committed and the next valid recovery action.

**P05-A5.** Export and workspace switching respect scope and do not expose another workspace’s private payloads.

## Failure and recovery coverage

Lost UI connection, delayed events, stale approval screen, revoked membership, unsupported undo and an unknown provider outcome.

## Scope boundary

A custom compositor, generated arbitrary privileged HTML/JavaScript or a UI mock presented as runtime evidence.
