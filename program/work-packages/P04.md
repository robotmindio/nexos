# P04 — Durable local jobs and effect reconciliation

Status: implementation and qualification pending. Dependencies and coverage are canonical in [plan.json](../plan.json); mutable state is in [state.json](../state.json).

## User-visible outcome

A bounded job survives worker/client failure, exposes durable progress and resumes with valid authority while handling uncertain external outcomes honestly.

## Implementation work

1. Implement the minimum local durable job/checkpoint/attempt contract and audit a Recuriant adapter. Reuse existing durable execution when suitable; do not duplicate a generic workflow platform.

2. Persist task and attempt identities separately, checkpoint compatibility and provider effect keys. Authority is revalidated on resume; a checkpoint cannot embed everlasting credentials.

3. Implement pause, cancel request, interruption, retry and terminal outcomes as distinct operations. Cancellation stops new permitted work according to the provider boundary; it does not undo committed effects.

4. Use explicit reconciliation for effects where dispatch succeeded but receipt persistence failed. Honor provider idempotency limits and retain reservations for unresolved liability.

## Acceptance

**P04-A1.** E02 kills a worker and restarts the daemon/client, then resumes a real multi-step task from a recorded checkpoint.

**P04-A2.** Idempotent provider operations are deduplicated according to their real contract. An ambiguous non-idempotent operation is quarantined until reconciliation or authorized resolution.

**P04-A3.** Expired or revoked authority prevents resumed effects while permitting authorized state inspection.

**P04-A4.** Budget reservations are recovered and settled correctly after process failure; failures cannot free liability prematurely.

**P04-A5.** A saved job, artifact and receipt remain inspectable with model access and optional remote services disabled.

## Failure and recovery coverage

Kill before/after dispatch and before/after receipt commit; lose response; corrupt a checkpoint; race cancellation with dispatch; restart with a different compatible worker build.

## Scope boundary

Transparent continuation of arbitrary process memory or claims that durable task retry alone guarantees exactly-once external effects.
