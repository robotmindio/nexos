# P10 — Federation with explicit authority and fencing

Status: implementation and qualification pending. Dependencies and coverage are canonical in [plan.json](../plan.json); mutable state is in [state.json](../state.json).

## User-visible outcome

Two qualified nodes share declared work and resources while retaining clear authority, partition behavior and honest recovery guarantees.

## Implementation work

1. Implement authenticated node identity, scoped resource offers, checkpoint transfer and lease/fencing rules. Keep one authoritative writer for each workspace state domain unless a distinct conflict protocol is explicitly qualified.

2. Bind grants and budgets to remote execution and recheck them at effect boundaries. Partitioned workers cannot mint fresh authority or keep spending an expired allocation.

3. Implement checkpoint compatibility and resource admission; move logical tasks only through declared checkpoints. Preserve lineage and confidentiality during transfer.

4. Use a real two-node test target. A second process in one namespace qualifies neither node isolation nor network-partition behavior.

## Acceptance

**P10-A1.** E07 allocates work to the second real node, produces evidence and resumes after an induced link partition.

**P10-A2.** A stale worker cannot commit a fenced managed operation after its lease expires and a replacement is admitted.

**P10-A3.** Non-fenceable external providers expose their bounded guarantee and ambiguous outcomes; tests do not infer stronger fencing.

**P10-A4.** Unauthorized nodes, replayed leases and mismatched checkpoint versions are rejected.

**P10-A5.** Local work allowed by valid local grants remains usable during a partition; unavailable remote work is explicit.

## Failure and recovery coverage

Partition, delayed response, stale writer, node reboot, clock skew assumptions, revoked credential and concurrent resource claims.

## Scope boundary

Universal process migration, unlimited offline autonomy, arbitrary active-active metadata writes and robot safety certification.
