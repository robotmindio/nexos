# P13 — Qualified RobotMind ecosystem adapters

Status: implementation and qualification pending. Dependencies and coverage are canonical in [plan.json](../plan.json); mutable state is in [state.json](../state.json).

## User-visible outcome

Selected real RobotMind services participate in a NexOS workflow through thin adapters with explicit ownership, authority and recovery semantics.

## Implementation work

1. Start from the pinned observations in docs/INTEGRATION.md, including session-relay durable outcomes, workspace-provisioner, PC capability/grant contracts and the shared Bifrost codebase. Revalidate exact revisions before implementation.

2. Qualify named Recuriant, NoemaDB, Secretary, identity or development adapters only when they contribute to the assigned product experience. Do not make every mentioned project a release dependency.

3. Map authentication, grants, context, effects, costs, checkpoints and status without duplicating the provider’s authoritative state. Document unsupported semantics and migration ownership.

4. Run at least one real end-to-end workflow across the selected adapter and the broker, then exercise provider restart, denial, timeout and ambiguous outcome.

## Acceptance

**P13-A1.** Every qualified adapter names repository/path/revision, API version, real endpoint environment, provider owner and exact supported claims.

**P13-A2.** The selected workflow produces actual outputs and receipts, with no production mock or fixture substituted for an unavailable service.

**P13-A3.** Authority and budget cannot amplify through translation; unknown provider outcomes remain unknown until reconciled.

**P13-A4.** Provider outage degrades only its capabilities; local deterministic workspace use remains available.

**P13-A5.** Duplicated/superseded paths are removed only after migration validation; no second Bifrost or general durable engine is introduced.

## Failure and recovery coverage

Unavailable credentials, API drift, webhook replay, double delivery, provider restart, stale schema and confidential metadata leakage.

## Scope boundary

A blanket claim that all of RobotMind is integrated, audit notes treated as successful integration or replacement infrastructure without a demonstrated contract gap.
