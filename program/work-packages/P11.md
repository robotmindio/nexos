# P11 — Reference distribution, updates and recovery

Status: implementation and qualification pending. Dependencies and coverage are canonical in [plan.json](../plan.json); mutable state is in [state.json](../state.json).

## User-visible outcome

A user installs and updates a pinned reference image, retains a usable recovery route and understands which system/configuration/data states can be restored.

## Implementation work

1. Build the NixOS reference image and installation recipe from real pinned inputs. Keep ordinary Linux compatibility and deterministic core operation.

2. Define system/runtime/data migration compatibility, preflight checks, backups, fallback boot and recovery credentials. Separate Nix generation switching from application data restoration.

3. Validate update failure points, schema changes and recovery after interruption. Refuse unsafe downgrade or restore when data compatibility is unproven.

4. Provide export and clean uninstall/rollback behavior for the managed runtime; do not remove unrelated host data.

## Acceptance

**P11-A1.** E10 installs a fresh image, upgrades a real prior qualified build and restores its declared compatible checkpoint after failure.

**P11-A2.** Power-loss-style interruption at installation/update stages leaves a documented recoverable state; actual recovery is demonstrated in the VM tuple.

**P11-A3.** An incompatible data-schema downgrade is blocked with a clear recovery path rather than silently corrupting data.

**P11-A4.** E08 ordinary application use, accessibility and no-model operation still pass after the update.

**P11-A5.** Restored keys/grants follow the declared revocation and secret-handling policy; backup verification checks actual contents and digests.

## Failure and recovery coverage

Disk full, bad update signature/provenance, corrupted image, interrupted generation switch, incompatible database schema and failed backup.

## Scope boundary

Every hardware platform, secure-boot attestation unless separately qualified or whole-world rollback.
